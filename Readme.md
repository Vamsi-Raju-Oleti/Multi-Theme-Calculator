# Multi-Theme Calculator 🧮✨

A premium, modern calculator web application built with HTML, CSS, and Vanilla JavaScript. Designed for a developer portfolio, this project features a stunning glassmorphism UI, smooth animations, and a fully customizable multi-theme experience.

## 🚀 Features

- **Core Functionality:** Basic arithmetic operations (+, -, ×, ÷, %), decimal support, clear, and delete.
- **Multi-Theme Engine:** - **Dark & Light Modes:** Seamlessly toggle between deep dark mode and clean light mode.
  - **Color Palettes:** Choose from 4 vibrant accent colors (Purple, Ocean Blue, Forest Green, Sunset Orange).
- **Persistent Preferences:** Uses `localStorage` to remember your chosen theme and color across sessions.
- **Premium UI/UX:** - Glassmorphism card design with backdrop blurs.
  - Neon glow effects for operators and the equals button.
  - Custom JavaScript-powered ripple effects on button clicks.
- **Keyboard Support:** Full keyboard accessibility (Numpad, Enter, Backspace, Escape).
- **Error Handling:** Gracefully handles invalid inputs and division by zero.
- **Fully Responsive:** Looks great on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure and inline SVG icons.
- **CSS3:** CSS Variables (Custom Properties), Flexbox, CSS Grid, Glassmorphism techniques, and CSS Animations.
- **JavaScript (ES6+):** Object-Oriented Programming (Classes), DOM Manipulation, Event Listeners, and Local Storage management. No external libraries or frameworks.
